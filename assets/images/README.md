## 💡 替换提示
1. **替换格式**：建议使用 `.jpg` 或 `.png`。如果使用 `.png` 或其他扩展名，只需在 [index.html](../../index.html) 中将对应的 `.jpg` 后缀改为 `.png` 即可。
2. **图片压缩**：建议单张图片大小控制在 `1MB` 以内，以确保国内和手机端访问秒开。
